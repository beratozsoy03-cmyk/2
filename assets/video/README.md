# Video dosyaları

Aşağıdaki adlarla dosyayı bu klasöre yüklemek yeterlidir; sayfa otomatik kullanır.

| Dosya | Kullanım | Öneri |
|---|---|---|
| `hero.mp4` | Ana sayfa hero | MP4 (H.264), ses yok, 16:9 1920x1080, 8-15 sn, döngü, 3-6 MB |
| `hero-mobil.mp4` | Ana sayfa hero (mobil, isteğe bağlı) | 9:16 veya 4:5, 720p, 2-4 MB |
| `seminer.mp4` | Seminer hero | hero.mp4 ile aynı |
| `seminer-mobil.mp4` | Seminer hero (mobil, isteğe bağlı) | hero-mobil.mp4 ile aynı |

Proje, öğrenci ve Instagram videoları/görselleri için `js/content.js` dosyasındaki örnek satırlara bakın.
